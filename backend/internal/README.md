# internal
Any new packages should atlest follow this structure (this is a rule but only a recommendation)

| File      | Use                                    |
|-----------|----------------------------------------|
| errors.go | Reusable errors                        |
| values.go | Constant values                        |
| types.go  | Structs or interfaces                  |
| utils.go  | Internal helper functions              |
| README.md | Explanation and info about the package |


Happy Coding and Good Luck!
